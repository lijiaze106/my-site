Website Project Planning

Five Candidate Project Ideas

Idea 1: WeatherFit — Weather Meets Sports

  • Audience: Students and exercise beginners
  • Four pages: Home, Your Plan, Sports Guide, About
  • Core page: Your Plan
  • Minimum version: Type in the place and today's weather by hand (e.g. sunny, 25°C), then see suggested sports and a gear list

Idea 2: Beginner hiking guide

  • Audience: New hikers who want simple outdoor tips
  • Four pages: Home, Gear List, Safety Tips, Local Trails
  • Core page: Safety Tips
  • Minimum version: Text guide + simple images, no interactive tools

Idea 3: My reading notes site

  • Audience: Students who read fiction books
  • Four pages: Home, Book List, Book Reviews, Quotes
  • Core page: Book Reviews
  • Minimum version: Collection of book notes and quotes

Idea 4: Simple photography portfolio

  • Audience: People who want to view my photos
  • Four pages: Home, Gallery, About, Contact
  • Core page: Gallery
  • Minimum version: Photo gallery with short descriptions

Idea 5: Fridge Chef

  • Audience: Students who cook for themselves
  • Four pages: Home, Ingredient Search, Recipes, About
  • Core page: Ingredient Search
  • Minimum version: Pick ingredients and see a few matching recipes

Final Chosen Project: WeatherFit — Weather Meets Sports

Why I chose it

  • It answers a real everyday question: "Can I do my sport today, and what should I bring?"
  • It lets me practise HTML, CSS and JavaScript together, including a form and a bit of JavaScript logic
  • I enjoy sports, so I will keep improving it

Advantages

  • Useful: gives a quick answer on which sports suit the weather and what gear to bring
  • Simple to start: the first version only needs one form (place + weather) and a result box on the same page
  • Easy to grow: more sports and features can be added later
  • No outside services: the user types the weather in, so there is no API or key to set up
